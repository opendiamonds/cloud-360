# User Flow — 成本估算與 FinOps（C1 第一輪）

## 上游輸入

- **intent-statement**：架構師產圖後要可對外說明的成本數字；FinOps 要可拆解、可覆寫、可設預算。
- **scope-document**：第一段（擷取／報價／畫面／入口）可單獨上線；第二段為預算與超支。
- **intent-backlog**：PU-4／PU-5／PU-6 的使用者面。

## Flow 1 — 雲端架構師產圖後看估價（第一段主流程）

1. 在 Workspace 產圖成功。
2. 成功卡點「查看預估成本」[Q2]。
3. 看到總額、圓餅、資源列；未定價列名且不計入總額。
4. 改各列每日時數，該列小計與總額重算。
5. 若需對外說明，抄錄總額與來源時間。

**Error paths**：官方價失敗 → 列可覆寫並標 Manual Override，不空白失敗 [intent:Q15]。無權限 → 沿用既有 403 頁。

## Flow 2 — FinOps 設預算與覆寫（第二段）

1. 從 Sidebar「成本 > 預估成本」進入。
2. 若尚無圖或未選擇：空狀態，從頁首下拉選擇或前往產圖。
3. 選圖後進入與 Flow 1 同一成本畫面（預選上次選擇的圖）。
4. 在總額旁設定本圖每月預算 [Q6]。
5. 缺價列就地填單價，列上出現 Manual Override [Q4]。
6. 總額超過預算時，總額旁出現「已超支」[Q3]。

**Error paths**：非 FinOps 改單價 → 欄位不可編（權限切法留設計，線框只畫可編態）。

## Flow 3 — 工程主管／架構師看到超支橫幅

1. 登入後進入任一受保護頁。
2. 該圖仍超支 → 頂部橫幅，不能永遠關閉 [feas:Q6]。
3. 「前往成本畫面」回到 Flow 1／2 的同一頁。

## Assumptions & Open Questions

- [assumption] 橫幅綁「使用者有權看到的超支圖」，多圖時如何堆疊留 refined-mockups
- [assumption] Flow 2 的不可編態細節留設計（三種變更權尚未切權限模型）
- [assumption] 「上次選擇的圖」記在本瀏覽器／session，不跨裝置同步；無紀錄時走空狀態
