### Findings

| # | Severity | Location | Finding | Recommendation |
|---|---|---|---|---|
| 1 | Major | M5 全未定價 | 「全未定價」狀態僅以文字說明（「不渲染已完成估價語意的總額數字」），無 ASCII 示意畫面。開發者面對三種合理實作：（a）完全移除「每月總額」section；（b）保留「每月總額」heading 但以替代文字取代數字；（c）保留 heading 並顯示「0 命中」但不賦予「已完成估價」語意。test-id `cost-total` 0 命中可被測試，但圓餅區是否同步消失、「每月總額」heading 保留與否在任何現有文件中皆未釐清，不同實作在 design review 或 QA 視覺審查時會有明顯差異。 | 補 M5「全未定價」ASCII panel：明確標注「每月總額」heading 是否保留、該 section 顯示什麼替代文字（如「尚無已定價列」或省略）、h2「圓餅拆解」section 是否一同隱藏。可將零節點與全未定價合併在同一畫面中以雙欄說明。 |
| 2 | Minor | M8 多圖超支橫幅 | 多圖超支橫幅缺乏 ASCII 示意與具體文字格式。M8 主體只呈現單圖超支橫幅，多圖情境以文字一句帶過「顯示數量並點名至少一張」。QA 撰寫「橫幅含超支圖數量」的 Playwright 斷言時，無法確認要比對的字串格式（例如「2 張圖超支，包含 web-tier-aws」vs「! 2 張圖超支 · 包含 web-tier-aws」）。 | 在 M8 後方補一行多圖超支的示意文字，例如 `! 2 張圖超支，包含 web-tier-aws · [前往成本畫面]`；並說明「前往成本畫面」預選的圖 id 屬於哪張（AC-7.4 已定義「超支集合中的一張」，但建議明確為「第一張可見的超支圖」以讓 Playwright 斷言穩定）。 |
| 3 | Minor | interaction-spec RegionField | `RegionField` 控件類型未定案：「Alex `<select>` 或文字碼」同時允許下拉選單與自由文字輸入兩種實作。Playwright 對 select 用 `selectOption()`、對 text input 用 `fill()`，兩者互不通用。在 application-design 定案控件類型之前，QA 無法撰寫確定的估價區域鍵盤操作測試。 | 在 interaction-spec `RegionField` 欄補注「暫定 `<select>`，application-design 階段可更換」或反之，讓 QA 有明確的預設假設可寫 Playwright 測試；最終由 application-design 凍結。 |

### Summary

七則 Must 故事均有對應畫面（M1–M10）且與 stories.md / requirements.md 完整追溯。第一段禁橫幅/預算/超支欄的 DOM 不掛約束（非 CSS hidden）在 mockups、interaction-spec、design-system-mapping 三份文件中一致且可驗證。SVG 圓餅附文字清單（Q1=A）、橫幅在主區 Sidebar 右側（Q3=A）、無新設計系統（Q5=A）、無 C2/C3 漏入，均通過審查。零 Critical；一項 Major（M5 全未定價缺 ASCII 畫面）不阻擋工程啟動，但需在 construction 前補齊以避免實作分歧；兩項 Minor 均有工程可參照的上游描述，不阻擋。
