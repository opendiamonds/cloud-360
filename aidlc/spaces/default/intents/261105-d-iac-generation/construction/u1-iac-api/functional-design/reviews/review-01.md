### Summary

One Critical defect blocks construction: the shared contract-summary.md OpenAPI marks `POST /scan`'s `diagram_id` as optional ("可選"), directly contradicting the Q2=A decision (BR1.2) that closes R-02 by making it mandatory. Because U2 and TestClient implement against the contract, not the business rules, R-02 would remain open in practice even though the functional design declares it closed. Two Major defects compound this: the `missing_diagram_id` error code named in BR1.2 is absent from the GateError enum (leaving implementers unable to satisfy the rule), and `DraftSummary.module_tree` is not marked required for succeeded drafts (breaking the US2.1 AC2.1.1 assertion that the file tree is always present on success). The three minor defects (missing state-machine transition, undefined `diagram_mismatch` trigger, unspecified reportId selection on D3) are individually resolvable with small additions to rules.md or the state diagram. All six findings are mechanically verifiable against the artifact text above.
