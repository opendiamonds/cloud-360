# Wireframes — IaC Workspace (Low-fi)

Desktop web 為主；嚴格沿用 A／C Workspace layout／元件語彙。[Q4][Q5]

## Screen 1 — Workspace entry

**a11y：** h1 工作區標題；landmark：header、nav（工作區工具）、main；鍵盤：Tab 至「生成 IaC」按鈕。[Q6]

```text
+------------------------------------------------------------------+
| header: Workspace / 專案名                         [user][menu]  |
+----------+-------------------------------------------------------+
| nav      | main                                                  |
| 圖面     |  [架構圖畫布 / 既有內容]                              |
| 設計 A   |                                                       |
| 評估     |                                                       |
| 成本 C   |                                                       |
| *生成IaC*|  <-- 由 Coming Soon 改為可點入口 [Q1]                |
| ...      |                                                       |
+----------+-------------------------------------------------------+
```

## Screen 2 — IaC work area (draft primary)

**a11y：** h1「IaC 生成」；h2 步驟（生成／掃描／Secrets）；landmark：nav（步驟）、main（草稿）、complementary（掃描／警告）；鍵盤：步驟按鈕與下載為可見焦點。[Q6]

```text
+------------------------------------------------------------------+
| header: IaC 生成（同 Workspace chrome）                          |
+----------+---------------------------+---------------------------+
| steps    | main: 草稿 (primary) [Q3] | aside: 次要 [Q3]          |
| 1 生成 * | 檔案樹 | HCL 預覽         | 脈絡：所選架構圖           |
| 2 掃描   |  a.tf  | resource "..."   | Agent 狀態（D1）           |
| 3 Secrets|  b.tf  | ...              | [下載] [複製]              |
|          |                           |                           |
|          |                           | (掃描區於此步驟後填入)    |
+----------+---------------------------+---------------------------+
| footer actions: [執行 D1] [下一步：掃描]                         |
+------------------------------------------------------------------+
```

## Screen 3 — Scan step (D2)

**a11y：** h2「靜態掃描」；findings 用列表／表格，嚴重度可讀文字非僅色票；鍵盤：列可聚焦。[Q6]

```text
+------------------------------------------------------------------+
| steps: 1 生成 ✓ | 2 掃描 * | 3 Secrets                           |
+----------+---------------------------+---------------------------+
| 草稿仍可見（唯讀或可切回）           | findings                   |
| 檔案樹 | HCL                         | HIGH  ... IAM *           |
|                                      | MED   ... sg open         |
|                                      | [重新掃描]                |
+----------+---------------------------+---------------------------+
| [上一步] [下一步：Secrets]                                       |
+------------------------------------------------------------------+
```

## Screen 4 — Secrets step (D3)

**a11y：** h2「Secrets」；警告用 status／alert 語意；不顯示 production 明文。[Q6][intent]

```text
+------------------------------------------------------------------+
| steps: 1 ✓ | 2 ✓ | 3 Secrets *                                   |
+------------------------------------------------------------------+
| main:                                                            |
|  ! 偵測到疑似明文／建議改為 Secret Manager 引用（示意）          |
|  建議區塊列表（路徑／變數名）— 不含真實密文                      |
|  [下載更新後草稿]                                                |
|                                                                  |
|  無「套用到雲端」按鈕（不代 apply）[Q2]                           |
+------------------------------------------------------------------+
| [完成並返回 Workspace]                                           |
+------------------------------------------------------------------+
```

## Information Architecture

| Priority | Content |
|---|---|
| Primary | 草稿檔案樹＋HCL [Q3] |
| Secondary | 掃描 findings、secrets 警告 [Q3] |
| Chrome | 與 A／C 相同 header／nav／agent 狀態語彙 [Q4] |

## Non-goals in UI

- 不提供代 apply／雲端帳號綁定部署鈕。[Q2][scope]
- 不引入獨立 `/iac` 路由為主路徑。[Q1]=A
