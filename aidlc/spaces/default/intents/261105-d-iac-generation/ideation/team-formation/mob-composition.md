# Mob / Collaboration Composition

## Preferred Topology

**Solo／pair＋AI-DLC**（本 repo 現行模式）。[Q5]

- Driver：luojingting（或 pair 同伴若有）  
- Navigator／加速：AI-DLC agents  
- 審閱：必要時一名審閱者，非固定 mob [Q1]

不採用固定 mob sessions，亦不依 D1／D2／D3 輪值不同人主導。[Q5]=A（未選 B／C）

## Working Agreement

| Topic | Agreement |
|---|---|
| 時區 | 不影響；同區或非同步可接受 [Q6] |
| 溝通 | 以 PR／workflow 閘門為主；審閱者按階段介入 [Q1][Q8] |
| 決策 | 工程師拍板；審閱者影響優先序 [Q8] |
| 外部 | 無 PS／承包商 [Q7] |

## RACI (lightweight)

| Activity | luojingting | AI-DLC | Reviewer |
|---|---|---|---|
| Ideation／Inception 產物 | A／R | C | C（視閘門） |
| Construction 實作 | A／R | C | I／C |
| 範圍變更 | A | C | C |
| 合併／部署觸發 | A／R | — | I |

R=Responsible, A=Accountable, C=Consulted, I=Informed。[Q1][Q8]

## Onboarding

單人為主路徑：無需正式 onboarding checklist；新審閱者只需指向 `<record>/ideation/` 與 scope-document。[Q1]
